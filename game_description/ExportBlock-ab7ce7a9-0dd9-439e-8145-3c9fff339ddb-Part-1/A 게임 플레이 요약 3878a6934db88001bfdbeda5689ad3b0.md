게임 시작 시

맵 선택 → 캐릭터 선택 → 카드덱 선택 (레퍼런스 : 뱀서)

이때 한번 깬 맵은 무한 모드 가능 (보스 클리어 후 계속 보스가 나오는 모드)

캐릭터는 각각 고유의 특성을 지님 (스텟, 카드군, 고유 플레이 방식등이 존재)

캐릭터 해금 존재

카드덱 해금 존재

맵은 다각형 이나 원으로 이루어져 있음 (추후 계층형 맵 기획 예정)

스테이지 구조 (레퍼런스 : 슬더슬)

노드 선택형 구조

맵 마다 최대 노드 수가 다름

한 스테이지가 끝날 때마다 3개의 노드 등장

노드의 종류는 맵/스테이지 시스템 참고

전투 노드에선 주어지는 시간동안 살아남아야함

이외 노드는 시간 제한 없음

노드에서 카드가 뜨는 것은 현재 덱에 있는 카드와 같은 종류의 카드가 뜰 확률이 높음(가중치)
