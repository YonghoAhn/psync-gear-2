| 역할 | 설명 |
| --- | --- |

# 카드군 구조 (여기 밑으로 좀 깊게 생각중인데 ㄱㄷ)

Carbo의 카드군 구조는 다음과 같이 3단계로 구성된다.

```
큰 카테고리
↓
작은 카테고리
↓
카드군
```

## 구조 설명

| 단계 | 설명 |
| --- | --- |
| 큰 카테고리 | 카드군을 보기 쉽게 구분하기 위한 상위 분류 |
| 작은 카테고리 | 비슷한 성향의 카드군을 묶는 실질적 시너지 단위 |
| 카드군 | 실제 카드가 속하는 가장 구체적인 빌드 단위 |

---

## 큰 카테고리의 역할

큰 카테고리는 주로 정리와 구분을 위한 분류다.

큰 카테고리 자체가 강한 시너지를 가지기보다는, 플레이어가 카드군을 이해하기 쉽게 해주는 역할이다.

---

## 작은 카테고리의 역할

작은 카테고리는 실제 시너지의 중간 단위다.

같은 작은 카테고리에 속한 카드군들은 서로 연계가 잘 되도록 설계한다.

예를 들어:

```
큰 카테고리: 원소
작은 카테고리: 자연 원소
카드군: 물, 번개, 냉기
```

이 경우 물, 번개, 냉기는 같은 작은 카테고리에 속하므로 서로 연계가 강하다.

# 카드 획득 방식

카드는 기본적으로 **휴식 노드를 제외한 모든 노드에서 획득 가능**하다.

즉, 휴식 노드는 카드 획득보다 회복, 강화, 제거, 정제에 집중한다.

## 노드별 카드 획득

| 노드 | 카드 획득 가능 여부 | 설명 |
| --- | --- | --- |
| 전투 노드 | 가능 | 전투 승리 후 카드 보상 |
| 엘리트 노드 | 가능 | 네임드 처치 후 높은 등급 카드 보상 |
| 상점 노드 | 가능 | 재화로 카드 구매 |
| 휴식 노드 | 불가능 | 회복, 강화, 제거, 정제 중심 |
| 이벤트 노드 | 가능 | 선택지에 따라 카드 획득 가능 |
| 보스 노드 | 가능 | 보스 처치 후 강력한 카드 또는 해금 보상 |

---

## 기본 카드 보상 구조

```
전투 승리
↓
카드 보상 3장 제시
↓
1장 선택 또는 스킵
↓
덱에 추가
```

# 카드 강화

카드 강화는 현재 두 가지 방식이 후보로 있다.

| 방식 | 설명 |
| --- | --- |
| A안 | 단순히 카드의 스탯이 강화되는 방식 |
| B안 | 같은 카드나 같은 카드군을 일정 수 이상 모으면 윗단계로 강화되는 방식 |

---

# 카드 강화 A안: 개별 카드 스탯 강화

카드 한 장을 선택해서 직접 강화하는 방식이다.

예를 들어:

```
화염탄
↓
화염탄 +1
↓
화염탄 +2
↓
화염탄 +3
```

강화될수록 피해량, 범위, 지속시간, 상태이상 확률, 쿨타임 등이 좋아진다.

## 장점

| 장점 | 설명 |
| --- | --- |
| 직관적임 | 플레이어가 이해하기 쉽다 |
| 밸런스 조절이 쉬움 | 수치 조절로 카드 성능을 관리하기 좋다 |
| 원하는 카드 집중 강화 가능 | 핵심 카드를 직접 키우는 느낌이 강함 |
| 휴식 노드와 잘 어울림 | 휴식 노드에서 강화 선택지를 주기 좋다 |
| 덱 정제와 연결 쉬움 | 적은 카드 수를 강화해 강한 덱을 만드는 재미가 생김 |

---

## 단점

| 단점 | 설명 |
| --- | --- |
| 변화감이 약할 수 있음 | 단순 수치 증가만 있으면 재미가 부족함 |
| 강한 카드만 반복 강화 가능 | 특정 카드 편중이 생길 수 있음 |
| 카드 수집 재미가 약해질 수 있음 | 같은 카드군을 모으는 동기가 낮아질 수 있음 |
| 빌드 폭발감이 부족할 수 있음 | 일정 수 이상 모아서 진화하는 느낌은 약함 |

---

## 보완 방법

A안을 쓸 경우 단순 수치 강화만 하지 말고, 특정 단계에서 기능을 추가하면 좋다.

| 강화 단계 | 강화 방향 |
| --- | --- |
| +1 | 피해량 증가 |
| +2 | 상태이상 확률 증가 |
| +3 | 추가 효과 개방 |
| 각성 | 카드 작동 방식 변화 |

---

# 카드 강화 B안: 일정 수 이상 모으면 윗단계로 강화

같은 카드 또는 같은 카드군의 카드를 일정 수 이상 모으면 상위 단계로 강화되는 방식이다.

예를 들어:

```
화염 카드 3장 보유
↓
화염 카드군 1단계 시너지 발동

화염 카드 6장 보유
↓
화염 카드군 2단계 시너지 발동

화염 카드 9장 보유
↓
화염 카드군 3단계 시너지 발동
```

또는 같은 카드를 여러 장 모아 진화할 수도 있다.

```
화염탄 3장
↓
강화 화염탄 1장으로 합성
```

---

## 방식 B-1. 같은 카드 중복 강화

| 조건 | 결과 |
| --- | --- |
| 화염탄 2장 | 화염탄 +1 |
| 화염탄 3장 | 화염탄 +2 |
| 화염탄 4장 | 화염탄 진화 |

### 장점

| 장점 | 설명 |
| --- | --- |
| 수집 재미가 강함 | 같은 카드를 모으는 목표가 생김 |
| 자동 성장 느낌 | 덱이 자연스럽게 강해지는 느낌 |
| 보상 선택이 쉬워짐 | 중복 카드도 가치가 생김 |
| 모바일/오토배틀러식 재미 | 조합, 승급, 진화의 쾌감이 있음 |

### 단점

| 단점 | 설명 |
| --- | --- |
| 운 영향이 커짐 | 원하는 카드가 안 나오면 강화가 어려움 |
| 덱이 두꺼워질 수 있음 | 중복 카드를 많이 집어야 해서 덱 정제가 어려움 |
| 특정 카드 의존도 증가 | 핵심 카드 중복 여부가 너무 중요해질 수 있음 |
| 밸런스가 어려움 | 진화 카드가 너무 강하면 게임이 흔들림 |

---

## 방식 B-2. 카드군 개수 기반 강화

같은 카드가 아니라, 같은 카드군의 카드 수에 따라 시너지가 열리는 방식이다.

예를 들어:

| 화염 카드 보유 수 | 효과 |
| --- | --- |
| 2장 | 화염 피해 +5% |
| 4장 | 연소 중첩 +1 |
| 6장 | 연소 상태 적 처치 시 작은 폭발 |
| 8장 | 모든 화염 카드가 연소 대상에게 추가 피해 |

### 장점

| 장점 | 설명 |
| --- | --- |
| 빌드 방향성이 명확해짐 | “나는 화염 빌드다”라는 느낌이 강함 |
| 중복 강제 부담이 적음 | 같은 카드가 아니라 같은 카드군이면 됨 |
| 카드군 정체성 강화 | 카드군별 특징을 살리기 좋음 |
| 작은 카테고리 시너지와 잘 맞음 | 카드군 구조와 자연스럽게 연결됨 |

### 단점

| 단점 | 설명 |
| --- | --- |
| 특정 카드군 몰빵 유도 | 혼합 빌드보다 단일 카드군이 유리해질 수 있음 |
| 덱 다양성 감소 가능 | 시너지 단계 때문에 비슷한 카드만 고를 수 있음 |
| UI 설명 필요 | 현재 몇 장으로 어떤 효과가 열렸는지 보여줘야 함 |
| 카드군 밸런스 중요 | 카드군별 시너지 단계가 비슷한 가치여야 함 |

---

## A안과 B안 비교

| 기준 | A안: 개별 카드 강화 | B안: 카드 수 기반 강화 |
| --- | --- | --- |
| 직관성 | 높음 | 중간 |
| 빌드 성장감 | 중간 | 높음 |
| 수집 재미 | 낮음~중간 | 높음 |
| 밸런스 난이도 | 낮음~중간 | 높음 |
| 운 영향 | 낮음 | 높음 |
| 덱 정제와 궁합 | 좋음 | 주의 필요 |
| 카드군 구조와 궁합 | 보통 | 좋음 |
| 플레이어 통제감 | 높음 | 중간 |
| 폭발적인 성장감 | 중간 | 높음 |

---

## A & B 혼합

> **개별 카드는 A안으로 강화하고, 카드군 시너지는 B안으로 성장한다.**
> 

즉:

| 시스템 | 적용 방식 |
| --- | --- |
| 카드 자체 강화 | A안 사용 |
| 카드군 시너지 강화 | B안 사용 |
| 같은 카드 중복 진화 | 일부 희귀 카드나 특수 카드에만 사용 |

---

### 개별 카드 강화

```
화염탄 → 화염탄 +1 → 화염탄 +2
```

### 카드군 시너지

```
화염 카드 3장 보유:
연소 피해 +10%

화염 카드 5장 보유:
연소 최대 중첩 +2

화염 카드 7장 보유:
연소 상태 적 처치 시 폭발
```

이렇게 하면 플레이어는 핵심 카드를 직접 강화하면서도, 카드군을 모으는 장기 목표를 가진다.

# 카드 삭제 / 정제

## 방식 A. 휴식 노드에서만 카드 제거 가능

| 장점 | 설명 |
| --- | --- |
| 휴식 노드의 가치가 높아짐 | 회복 대신 정제를 선택하는 고민이 생김 |
| 덱 정제가 강력한 선택이 됨 | 아무 때나 제거할 수 없어서 중요도가 높음 |
| 노드 선택의 전략성 증가 | 휴식 노드를 갈지 말지 고민하게 됨 |
| 덱빌딩 난이도 유지 | 카드를 무작정 집는 플레이를 억제함 |

| 단점 | 설명 |
| --- | --- |
| 제거 기회가 부족할 수 있음 | 휴식 노드를 못 만나면 덱이 지저분해짐 |
| 운 영향 증가 | 맵 구조에 따라 정제 가능성이 달라짐 |
| 초보자 답답함 | 잘못 고른 카드를 오래 들고 가야 할 수 있음 |
| 이벤트/상점 가치 감소 가능 | 정제를 휴식에만 몰아두면 다른 노드 기능이 제한됨 |

---

## 방식 B. 휴식 노드 + 상점에서 카드 제거 가능

| 장점 | 설명 |
| --- | --- |
| 제거 기회가 안정적임 | 휴식 노드를 못 가도 상점에서 해결 가능 |
| 재화 가치 증가 | 카드 제거가 재화 사용처가 됨 |
| 플레이어 통제감 증가 | 덱 정제를 계획적으로 할 수 있음 |
| 기존 덱빌딩 문법과 잘 맞음 | 플레이어가 이해하기 쉬움 |

| 단점 | 설명 |
| --- | --- |
| 휴식 노드 가치 일부 감소 | 상점에서도 제거 가능하면 휴식 고유성이 약해짐 |
| 재화만 많으면 정제가 쉬워짐 | 덱 관리 난이도가 낮아질 수 있음 |
| 상점 기능 과밀화 | 카드, 유물, 강화, 제거가 모두 몰릴 수 있음 |

---

## 방식 C. 모든 노드 보상에서 가끔 제거 선택지 등장

| 장점 | 설명 |
| --- | --- |
| 유연함 | 전투 후에도 정제 선택 가능 |
| 덱 관리 스트레스 감소 | 불필요한 카드 제거가 쉬움 |
| 플레이 템포 빠름 | 따로 휴식 노드를 기다리지 않아도 됨 |

| 단점 | 설명 |
| --- | --- |
| 정제의 가치가 낮아짐 | 너무 자주 제거하면 덱 압축이 쉬워짐 |
| 휴식 노드 약화 | 휴식의 핵심 기능이 줄어듦 |
| 선택 피로 증가 | 매 보상마다 제거까지 고려해야 함 |
| 밸런스 붕괴 가능 | 핵심 카드만 남기는 덱이 너무 쉽게 완성됨 |

# 카드 희귀도

Carbo의 카드 희귀도는 단순히 코스트가 높다고 높아지는 것이 아니라, **카드가 가질 수 있는 최대 파괴력과 연계 가능성**을 기준으로 정하는 것이 좋다.

즉:

> **희귀도 = 카드의 단독 성능 + 연계 시 최대 포텐셜 + 게임 규칙을 바꾸는 정도**
> 

로 판단한다.

---

## 희귀도 기준

| 희귀도 | 기준 |
| --- | --- |
| 일반 | 단순하고 기본적인 효과, 빌드의 기초 |
| 고급 | 조건부 효과나 작은 연계 가능 |
| 희귀 | 특정 빌드의 핵심 부품 |
| 영웅 | 강한 연계나 전투 흐름을 바꾸는 효과 |
| 전설 | 게임 규칙을 바꾸거나 빌드 전체를 완성시키는 카드 |

# 카드 연계 구조

| 연계 방식 | 설명 |
| --- | --- |
| 1. 서로 다른 카드군과의 연계 | 다른 카드군의 효과가 만나 새로운 반응 발생 |

# 연계 방식 1: 서로 다른 카드군과의 연계

## 개념

서로 다른 카드군의 효과가 전투 중 만나면 추가 반응이 발생한다.

이 방식은 카드군 조합의 재미를 만든다.

예를 들어:

```
물 카드군: 물장판 생성
↓
번개 카드군: 전기 공격 사용
↓
물장판에 전기 반응 발생
↓
범위 감전 피해
```

## 장점

| 장점 | 설명 |
| --- | --- |
| 카드군 조합 재미 | 서로 다른 카드군을 섞는 이유가 생김 |
| 전투가 화려해짐 | 지형 반응, 속성 반응이 시각적으로 잘 드러남 |
| 빌드 다양성 증가 | 단일 카드군뿐 아니라 혼합 빌드가 가능 |
| 플레이어 실력 반영 | 어떤 순서로 쓰느냐가 중요해짐 |

---

## 주의점

| 문제 | 해결 방법 |
| --- | --- |
| 너무 복잡해질 수 있음 | 초반에는 핵심 반응만 제공 |
| 플레이어가 모를 수 있음 | 카드 설명과 UI에 반응 표시 |
| 밸런스가 어려움 | 반응 피해는 별도 계수로 관리 |
| 우연히 터져서 혼란스러움 | 반응 발생 시 명확한 이펙트와 텍스트 표시 |

# 연계 방식 2: 같은 카드군과의 연계

QWERT 5개의 카드 슬롯에 배치된 카드 중, 인접한 슬롯에 같은 카드군 카드가 있고, 짧은 시간 안에 연속으로 사용하면 효과가 증폭된다.

예를 들어:

```
Q: 화염탄
W: 불씨 확산
E: 폭염 핵
R: 보호막
T: 순간이동
```

이때 Q-W-E가 모두 화염 카드군이라면, 짧은 시간 안에 Q → W → E 순서로 사용했을 때 화염 연계가 발생한다.

---

## 기본 규칙 예시

| 조건 | 효과 |
| --- | --- |
| 같은 카드군 카드 2장을 연속 사용 | 1단계 연계 |
| 같은 카드군 카드 3장을 연속 사용 | 2단계 연계 |
| 같은 카드군 카드 4장 이상 연속 사용 | 3단계 연계 |
| 연계 제한 시간 | 카드 사용 후 2초 이내 |
| 유틸/중립 카드 사용 | 연계를 끊지 않음 |
| 다른 카드군 카드 사용 | 기본적으로 연계 종료 |

## 장점

| 장점 | 설명 |
| --- | --- |
| 실시간 전투와 잘 맞음 | 카드 사용 순서와 타이밍이 중요해짐 |
| 슬롯 배치가 의미 있어짐 | QWERT 위치가 단순 UI가 아니라 전략 요소가 됨 |
| 손맛이 생김 | 콤보를 넣는 느낌이 강해짐 |
| 카드군 정체성 강화 | 같은 카드군을 모으는 이유가 생김 |

---

## 단점

| 단점 | 설명 |
| --- | --- |
| 조작 난이도 증가 | 초보자가 헷갈릴 수 있음 |
| 특정 배열 강제 가능 | 같은 카드군을 붙여야 해서 자유로운 배치가 줄어듦 |
| QWERT 방식에 의존 | 다른 조작 방식과 충돌 가능 |
| 너무 강하면 단일 카드군만 유리 | 혼합 빌드가 약해질 수 있음 |

# 연계 방식 3: 유틸 또는 중립 연계

유틸 또는 중립 카드는 사용해도 다른 카드군의 연계를 취소시키지 않는다.

---

## 예시

```
Q: 화염탄
W: 중력장
E: 폭염 핵
```

여기서 W의 중력장이 중립 또는 유틸 카드라면:

```
Q 화염탄 사용
↓
W 중력장 사용
↓
E 폭염 핵 사용
↓
화염 연계 유지
```

즉, 중력장 사용이 화염 연계를 끊지 않는다.

## 유틸/중립 카드의 역할

| 역할 | 설명 |
| --- | --- |
| 연계 유지 | 카드군 콤보 중간에 사용해도 흐름을 끊지 않음 |
| 위치 보정 | 적을 모으거나 이동해서 연계를 맞추기 쉽게 함 |
| 생존 보조 | 회피, 보호막, 정화 등을 사용해도 공격 연계가 유지됨 |
| 빌드 연결 | 서로 다른 카드군 사이의 다리 역할 |
| 전투 안정화 | 강한 콤보를 넣기 전 준비 시간을 제공 |
