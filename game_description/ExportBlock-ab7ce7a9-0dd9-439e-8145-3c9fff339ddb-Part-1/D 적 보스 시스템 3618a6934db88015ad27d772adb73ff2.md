## 잡몹 / 네임드 / 보스 시스템 개요

| 구분 | 역할 |
| --- | --- |
| 잡몹 | 플레이어의 빌드 성능을 테스트하는 기본 적 |
| 네임드 | 특정 패턴과 기믹을 가진 중간 난이도 적 |
| 보스 | 플레이어가 완성한 빌드를 검증하는 핵심 전투 대상 |

## 잡몹 유형

| 유형 | 설명 | 역할 |
| --- | --- | --- |
| 근접형 | 플레이어에게 접근해 공격 | 기본 압박 |
| 원거리형 | 일정 거리에서 투사체 발사 | 이동 강제 |
| 지원형 | 다른 적을 회복하거나 강화 | 우선 처치 대상 |
| 소환형 | 작은 적을 계속 소환 | 장기전 압박 |
| 방해형 | 둔화, 침묵, 표식 등 부여 | 상태이상 대응 유도 |

| 유형 | 설명 |
