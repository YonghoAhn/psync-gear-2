## 맵 / 런 구조 개요

Carbo의 런 구조는 **슬레이 더 스파이어 방식의 노드 선택형 맵**을 사용한다.

플레이어는 새 게임을 시작하면 하나의 맵을 배정받고, 여러 갈래의 노드 중 원하는 경로를 선택하며 진행한다. 

각 노드는 전투, 엘리트, 상점, 휴식, 이벤트 등으로 구성되며, 최종적으로는 반드시 **보스 노드**에 도달하게 된다.

---

## 기본 구조

```
시작 노드
↓
전투 / 이벤트 / 상점
↓
전투 / 엘리트 / 휴식
↓
전투 / 이벤트 / 상점 / 엘리트
↓
보스 노드
```
