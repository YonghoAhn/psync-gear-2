# 맵 목록

1. 끝없는 황금 초원
    
    지형 지물이 없는 초원 맵
    
2. 거목의 숲
    
    맵 가운데 큰 나무가 있으며 이외에도 여러 나무가 방해물로 존재
    
3. 버섯 숲
    
    작은 버섯들이 상태이상 유발
    
4. 홍수에 잠긴 밀림
    
    특정 시간마다 맵의 일정 부분이 잠김
    
    홍수 지역에서는 슬로우 발생
    
5. 초거대 핵발전소
    
    지역의 높낮이가 계속 변화함
    
6. 뒤집힌 방
    
    모든 행동이 반대로 발생
    
7. 만년빙
    
    플레이어 및 몹이 미끄러짐
    
8. 유성우
    
    맵에 지속적으로 유성이 떨어지면서 폭발 → 화염장판 생성
    
9. 폭풍의 눈
    
    바람이 불면서 플레이어 및 몹을 밀어내거나 당김
    
10. 태양의 도시
    
    맵 곳곳에 반사판이 설치되어 태양 레이저가 반사되어 플레이어 및 몹 공격
    
11. 미로
    
    맵이 시시각각 변화
