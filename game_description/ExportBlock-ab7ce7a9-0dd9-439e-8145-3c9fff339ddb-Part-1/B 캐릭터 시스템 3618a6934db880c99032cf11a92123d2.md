# 시작 카드군 시스템

Carbo에서는 모든 카드군이 처음부터 시작 카드군으로 등장하지 않는다.

캐릭터마다 선택 가능한 시작 카드군이 제한되어 있으며, 플레이어는 그중 하나를 선택해 런을 시작한다.

---

## 시작 카드군의 역할

| 역할 | 설명 |
| --- | --- |
| 초반 플레이 방향 결정 | 초반 전투 방식과 카드 구성이 정해짐 |
| 캐릭터 개성 강화 | 캐릭터마다 어울리는 카드군이 다름 |
| 빌드 출발점 제공 | 플레이어가 이번 런의 기본 방향을 선택 |
| 밸런스 조절 | 너무 강한 카드군이 초반부터 무조건 등장하지 않게 제한 |

---

# 캐릭터 해금

캐릭터는 처음부터 모두 사용할 수 있는 것이 아니라, 특정 **도전과제**를 클리어하면 해금된다.

## 해금 방식

| 해금 조건 유형 | 예시 |
| --- | --- |
| 클리어 조건 | 특정 보스를 처치하면 해금 |
| 카드군 조건 | 특정 카드군으로 클리어하면 해금 |
| 플레이 스타일 조건 | 회피, 패링, 소환, 상태이상 등 특정 방식으로 목표 달성 |
| 난이도 조건 | 높은 난이도에서 클리어 |
| 수집 조건 | 특정 유물이나 카드 조합 완성 |
| 실패/특수 조건 | 특정 저주를 가진 상태로 클리어 |
