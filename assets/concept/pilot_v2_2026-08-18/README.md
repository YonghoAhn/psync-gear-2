# Pilot Concept Art v2

Generated with the built-in ImageGen workflow on 2026-08-18.

## Direction

- Flat, hand-drawn 2D shapes instead of polished fantasy rendering
- Large-head chibi proportions and deliberately economical anatomy
- Limited cel shading, uneven contours, and restrained material detail
- Playful macabre character expressions
- Optional Y2K zine collage treatment using magenta, cyan, violet, and acid yellow
- Original characters and compositions; supplied images were used only as high-level visual references

## Selected outputs

- `01_demon_vanguard_flat.png`: black-background melee character sticker/key art
- `02_chibi_elemental_dash.png`: rough chibi dash animation concept
- `03_y2k_duo_promo.png`: low-fidelity two-character promotional collage

## Prompt set

The final prompts explicitly constrained gradients, glossy rendering, realistic anatomy, detailed costumes, cinematic lighting, and generic cyberpunk/fantasy polish. They emphasized four-to-six-color palettes, blunt silhouettes, imperfect linework, naive proportions, print misregistration, halftone blocks, and pixel stair-stepping.
