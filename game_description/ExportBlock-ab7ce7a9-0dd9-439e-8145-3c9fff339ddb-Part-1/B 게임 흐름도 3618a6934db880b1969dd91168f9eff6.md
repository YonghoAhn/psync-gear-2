## 한 판의 흐름

| 순서 | 단계 | 설명 |
| --- | --- | --- |
| 1 | 캐릭터 선택 | 플레이어는 고유 특성을 가진 캐릭터를 선택한다 |
| 2 | 시작 카드군 선택 | 이번 판의 초반 덱 방향성을 결정한다 |
| 3 | 전투 진입 | 적, 네임드, 보스와 실시간 전투를 진행한다 |
| 4 | 보상 선택 | 전투 후 카드, 강화 요소, 재화 등의 보상을 선택한다 |
| 5 | 덱 강화/정제 | 카드를 추가, 강화, 제거하며 덱의 완성도를 높인다 |
| 6 | 다음 전투 진입 | 변화한 덱과 빌드를 다시 전투에서 시험한다 |
| 7 | 빌드 완성 | 핵심 카드와 시너지가 갖춰지며 플레이 스타일이 확립된다 |
| 8 | 보스전 | 완성된 빌드로 보스를 공략한다 |
| 9 | 클리어 또는 패배 | 보스를 처치하면 클리어, 조건 실패 시 패배한다 |

## 게임의 승리조건

| 구분 | 내용 |
| --- | --- |
| 기본 승리 조건 | 보스 처치 |
| 중간 목표 | 전투를 통해 덱과 빌드를 성장시키기 |
| 최종 목표 | 완성된 빌드로 보스를 공략하고 클리어하기 |

## 게임의 패배 조건

| 패배 조건 | 설명 |
| --- | --- |
| 체력 0 | 플레이어의 체력이 모두 소진되면 패배한다 |
| 제한 시간 초과 | 정해진 시간 안에 전투 목표를 달성하지 못하면 패배한다 |
| 특수 기믹 실패 | 특정 보스나 전투에서 요구하는 기믹 수행에 실패하면 패배한다 |
| 포기 | 플레이어가 직접 게임을 포기하면 패배 처리된다 |
