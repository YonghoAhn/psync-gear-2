## 전투 방식

플레이어는 덱에서 카드를 끌어다 사이클을 만들 수 있음

덱에 있는 모든 카드는 모든 콤보에 들어가야함

콤보에 들어가는 카드 수의 제한은 없음

다만, 콤보에는 코스트가 존재하며 코스트를 초과할 경우 콤보가 완성되지 않음

(게임 시작 시 기본적으로 콤보가 완성되어있음)

모든 콤보는 자동 발동함과 동시에 순차적으로 반복되며 이러한 콤보들을 싸이클이라 함

즉, 플레이어는 자신의 싸이클을 만드는 것

예시 : 콤보 A → 콤보 B → 콤보 C → 콤보 A

---

## 콤보 및 세트 효과

하나의 콤보 안에서는 같은 카드군 끼리 시너지 효과를 발생 시킴

서로 다른 카드군이 껴있을 시 시너지 효과는 발생되지 않음

보조카드는 예외적으로 처리되며 시너지 효과에서도 제외됨

세트는 특정 카드군의 카드수 또는 카드의 레벨에 따라 추가적인 효과를 발생시킴

이러한 효과는 싸이클 전체에 적용됨

## 피해 계산식

최종 피해 = (기본 피해 + 카드 스탯 계수) × 치명타 배율 × 피해 증가 보정 × 방어력 보정 × 속성 저항 보정 × 난이도 보정

방어력 보정 = 100 / (100 + 방어력)

저항 보정 = 1 - 속성 저항률
